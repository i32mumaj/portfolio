# Portfolio — Jorge Muñiz

Portfolio personal hecho con React + Vite.

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción en dist/
```

Los enlaces (email, LinkedIn, URLs de los proyectos) se configuran en `src/config.js`.

Pulsa `º` (o `` ` ``) en cualquier parte de la página para abrir la terminal.
